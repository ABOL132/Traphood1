# راه‌اندازی بات تلگرامی — رایگان و ۲۴ ساعته (روی Render)

## قدم ۱: گرفتن توکن تلگرام
1. تو تلگرام برو به @BotFather
2. بزن `/newbot` و اسم و یوزرنیم بات رو انتخاب کن
3. یک توکن به این شکل بهت میده: `123456789:ABCdefGhIJK...`
4. جایی ذخیره‌اش کن — این همون `TELEGRAM_TOKEN` است

## قدم ۲: گرفتن API Key رایگان گوگل (Gemini)
1. برو به https://aistudio.google.com/app/apikey
2. با اکانت گوگلت وارد شو
3. روی "Create API Key" بزن
4. کلید تولیدشده رو ذخیره کن — این همون `GEMINI_API_KEY` است
5. این سرویس تا سقف مشخصی (چند صد درخواست در روز) کاملاً رایگانه

## قدم ۳: آپلود کد روی گیت‌هاب
1. یک اکانت رایگان در https://github.com بساز (اگه نداری)
2. یک ریپازیتوری جدید (Repository) بساز، مثلاً به اسم `editing-content-bot`
3. سه فایل `bot.py`، `requirements.txt` و همین `README.md` رو آپلود کن (دکمه‌ی Add file > Upload files)

## قدم ۴: دیپلوی روی Render (رایگان)
1. برو به https://render.com و با گیت‌هاب وارد شو
2. روی "New +" بزن → "Background Worker" رو انتخاب کن
3. ریپازیتوری‌ای که ساختی رو انتخاب کن
4. تنظیمات:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
5. برو بخش Environment و این دو متغیر رو اضافه کن:
   - `TELEGRAM_TOKEN` = همون توکنی که از BotFather گرفتی
   - `GEMINI_API_KEY` = همون کلیدی که از Google AI Studio گرفتی
6. روی "Create Background Worker" بزن

بعد از چند دقیقه، بات ۲۴ ساعته روشن و آماده‌ست. برو تو تلگرام بات رو باز کن و بزن `/start`.

## دستورات بات
- `/script <موضوع>` → اسکریپت ریلز با هوک قوی
- `/caption <موضوع>` → کپشن و هشتگ
- `/idea` → ۵ ایده محتوایی تازه

## نکته مهم
تحلیل «ترند روز» (چون نیاز به جست‌وجوی زنده‌ی وب داره) در این نسخه‌ی رایگان داخل بات نیست —
برای این کار همچنان از همین چت Claude استفاده کن (بگو «ترندهای امروز حوزه ادیت رو بررسی کن»)،
بعد موضوع رو با `/script موضوع` وارد بات کن تا اسکریپت بسازه.

## اگه بات بعد از مدتی خوابید
پلن رایگان Render گاهی سرویس‌های بی‌فعالیت رو غیرفعال می‌کنه. اگه بات جواب نداد،
کافیه از داشبورد Render دوباره روی "Manual Deploy" بزنی.
